# 8 Symbols Universe 🌌

> Visual Mandelbrot fractals, powered by Brainfuck's 8 symbols.

8 Symbols Universe is an interactive web application that showcases the power and beauty of computation using only the 8 commands of the Brainfuck language. Explore fractals, experiment with code, and visualize how simple instructions can generate stunning mathematical art. Designed for both learning and fun, this project combines a high-performance interpreter, a modern UI, and educational tools to make esoteric programming accessible and engaging for everyone.

---

- 🧠 Brainfuck interpreter (TypeScript)
- 🎨 Neon UI (React + Tailwind)
- 📊 Live memory/output
- 📖 Interactive tutorial & presets

## Quick Start

```bash
git clone https://github.com/manikeshmk/8-symbols-universe
cd 8-symbols-universe
npm install && npm run dev
# Visit http://localhost:3000
```
